# Property Talk

แอปฝึกพูดอังกฤษสำหรับนายหน้าอสังหา ขายเป็นชุดให้ลูกค้าแต่ละคน

## โครงสร้าง

- `core/` ส่วนกลางที่ใช้ร่วมกันทุกลูกค้า: `app.js`, `style.css`, `content.json` (บทสนทนาทั้งหมด), `audio/` (ไฟล์เสียง)
- `customers/<ชื่อ>/` โฟลเดอร์เล็กของลูกค้าแต่ละคน มีแค่หน้าเว็บกับไฟล์ตั้งค่าและรหัสเข้าใช้
- `tools/` สคริปต์เพิ่มลูกค้าและสร้างเสียง

แก้เนื้อหาใน `core/` ครั้งเดียว ลูกค้าทุกคนได้ของใหม่พร้อมกัน

## เพิ่มลูกค้าใหม่

บอก Claude ว่า "เพิ่มลูกค้า ชื่อ xxx" ระบบจะสร้างโฟลเดอร์ ออกรหัสเข้าใช้ 8 ตัว และผลักขึ้น GitHub ให้
ลิงก์ที่ส่งลูกค้าทาง Line จะเป็นรูปแบบ `https://<ชื่อผู้ใช้>.github.io/<ชื่อรีโป>/customers/<ชื่อ>/`
รหัสเข้าใช้ไม่ถูกเก็บในรีโป ต้องส่งให้ลูกค้าเองตอนสร้าง

## สร้างไฟล์เสียง (ทำครั้งเดียว)

1. สมัครบัญชีผู้ให้บริการเสียง สร้างคีย์ และตั้งวงเงินใช้จ่ายไว้ต่ำ ๆ
2. ในรีโปบน GitHub ไปที่ Settings > Secrets and variables > Actions > New repository secret
   ตั้งชื่อ `OPENAI_API_KEY` แล้ววางคีย์
3. ไปที่แท็บ Actions เลือก "Make audio" กด Run workflow
4. รอจนเสร็จ ไฟล์เสียงจะถูกบันทึกลง `core/audio/` เอง แอปจะเล่นไฟล์เสียงก่อน ถ้าไม่มีไฟล์จะใช้เสียงในเครื่องแทน

ดูจำนวนตัวอักษรที่จะสร้างก่อนได้ด้วย `python3 tools/make_audio.py --dry-run` (ไม่ต้องใช้คีย์)

## ข้อควรรู้เรื่องความปลอดภัย

- รหัสเข้าใช้ตรวจที่ฝั่งเบราว์เซอร์ ช่วยกันการแชร์ลิงก์แบบไม่ตั้งใจ แต่คนที่มีความรู้ทางเทคนิคเลี่ยงได้
- ถ้ารีโปเป็นสาธารณะ ใครก็เปิดดูไฟล์เนื้อหาและไฟล์เสียงได้โดยตรง ถ้าต้องการปกป้องเนื้อหาจริงจัง ต้องใช้ระบบสมาชิกฝั่งเซิร์ฟเวอร์
- แท็บล่ามสดและเครดิตเป็นต้นแบบ ปิดไว้ในชุดที่ขายจนกว่าจะต่อบริการแปลและระบบชำระเงินจริง
